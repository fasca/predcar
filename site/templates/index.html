Comment lire ce tableau

Chaque ligne est une génération d'un modèle. Plus le score est élevé, plus la génération cumule les signes d'un futur collector : elle est rare, elle disparaît moins vite que les modèles comparables, une partie de son parc est conservée hors route, et sa disparition a ralenti récemment.

Rang
Position au classement. 1 = potentiel le plus élevé.
Années
Années de production de cette génération.
Pays
Pays où la génération est observée. Le reste de la ligne agrège ces pays.
Parc
Véhicules encore en circulation, hors véhicules déclarés hors route (SORN).
Attrition/an
Part du parc qui disparaît chaque année. 3 % = le parc perd 3 % par an ; plus c'est bas, mieux le modèle se conserve. Une valeur négative signifie que le parc augmente — réimmatriculations ou imports. « — » : historique trop court.
Score
De 0 à 1, moyenne des quatre composantes ci-dessous, pondérée par {% for name, w in weights.items() %}{{ (w * 100) | round | int }} %{% if not loop.last %} / {% endif %}{% endfor %}. Une composante manquante est exclue et les poids restants recalculés, jamais comptée 0.
